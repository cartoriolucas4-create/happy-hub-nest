# Roadmap

## Painel do administrador geral (Super Admin)
- [x] Ações em massa: bloquear / desbloquear / liberar prazo (funções no banco)
- [x] Registro no histórico da troca de senha
- [ ] Identidade visual própria do painel (grafite/azul-aço) — parcialmente aplicada no SuperShell

## Configuração inicial obrigatória da barbearia
- [ ] Banner de prazo de acesso somente no Dashboard
- [ ] Nada pré-preenchido para barbearia nova (remover seed de meios de pagamento e valores padrão do onboarding)
- [ ] Checklist de configuração no Dashboard (dias, barbeiros, serviços, horários, pagamentos) com links
- [ ] Estado calculado a partir dos dados reais (não só booleano)
- [ ] Site público: bloquear agendamento e mostrar aviso amigável enquanto a configuração mínima estiver incompleta
- [ ] Proprietário continua acessando todas as páginas de configuração
- [ ] Barbearias existentes não perdem dados
